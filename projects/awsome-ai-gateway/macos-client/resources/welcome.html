AWSome Gateway — Claude 연결

회사 계정 로그인 도구와 개인 키 자동 갱신 도우미를 설치합니다. Git·Python·터미널 명령은 필요하지 않습니다.

Claude Desktop 자체는 별도로 설치해야 합니다. 설치 후 응용 프로그램의 AWSome Gateway Login을 열어 연결 프로파일을 검토·승인하고 회사 계정으로 로그인하세요.

프로파일은 시스템 범위의 Claude 연결을 회사 Gateway로 설정합니다. 기존 회사 관리 프로파일이 있으면 IT 담당자에게 먼저 문의하세요. 비밀번호나 개인 키는 설치 파일에 포함하지 않습니다.
